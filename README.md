
A collection of interesting websites from around the internet, all gathered in one place.

I created this project because I was bored and wanted an easy way to discover fun, useful, and unique websites. Whether you're looking to pass the time, explore something new, or find a cool tool, this site gives you a variety of websites to check out.

## Features

* Curated collection of websites
* Easy-to-use interface
* Quick access to entertaining and useful resources
* Regularly expandable with new discoveries

## Why I Made This

Sometimes you just want something interesting to do online. Instead of searching endlessly, this project brings together websites that are worth exploring, making it easy to find something fun when you're bored.

Enjoy exploring!
